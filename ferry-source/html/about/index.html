우도 시그니처는 우도 코코나라가 운영하는 민간 여행 가이드입니다. 배를 타기 전에 궁금한 정보를 정리하고, 우도에서의 이동과 먹거리를 함께 소개합니다.

누가 운영하나요?

전기차·스쿠터 대여 브랜드 코코나라가 운영하며, 같은 운영 브랜드인 달콤아재도 소개합니다. 브랜드 소개 영역에는 운영 관계를 표시합니다. 선사·항만·관광공사가 운영하는 공식 사이트는 아닙니다.

시간표와 오늘의 운항은 구분합니다

  • 월별 시간표와 요금은 출처가 있는 일반 안내로 제공합니다.
  • 당일 안내에는 운영자 입력 시각을 표시합니다.
  • 당일 특이사항이 없으면 평상시 정상운항 기준 안내를 표시하며, 당일 확정 정보와 구분합니다.
  • 운영자가 등록한 당일 공지는 기본 안내보다 우선하고, 날짜가 바뀌면 기본 안내로 돌아갑니다.
  • 데이터 연결 오류는 별도로 표시합니다.
  • 선사와 항구의 최신 안내가 이 사이트보다 우선합니다.

개인정보와 외부 서비스

이 사이트는 회원가입·예약 결제를 직접 받지 않습니다. 운항 안내를 불러오기 위해 Google Firebase의 공개 데이터에 접속하며, 지도·예약·브랜드 링크를 누르면 해당 외부 사이트로 이동합니다. 외부 사이트에는 각 서비스의 개인정보 처리방침이 적용됩니다.
