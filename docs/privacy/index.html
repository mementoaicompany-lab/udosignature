오늘·누적 방문 집계

2026년 10월 24일부터 각 브랜드 홈페이지의 방문 수를 별도로 집계합니다. 한국시간 자정을 기준으로 같은 브라우저의 하루 방문을 한 번으로 계산하며, 누적 수는 일별 방문을 합한 값입니다. 실제 사람 수나 예약 완료 수를 뜻하지 않습니다.

중복 집계를 줄이기 위해 이 사이트의 마지막 집계일을 브라우저의 로컬 저장소에 보관합니다. Firebase Realtime Database에는 브랜드별 날짜와 합계 숫자만 저장하며, 이 집계 코드가 이름·연락처·위치·방문 페이지·개인 식별자를 저장하지 않습니다. 다른 기기나 브라우저를 사용하거나 저장소를 삭제하면 새 방문으로 집계될 수 있습니다. 저장소 사용이 차단되거나 Do Not Track 신호가 켜져 있으면 숫자만 조회합니다.

인터넷 연결이나 통계 서비스 장애가 있으면 집계가 누락될 수 있으며 방문 수 자리에 ‘—’가 표시됩니다. 호스팅 및 통계 서비스 제공자는 서비스 운영·보안을 위한 접속 기록을 처리할 수 있습니다.

외부 서비스로 이동하는 경우

네이버 지도·예약·톡톡, 기존 고객 안내 등 외부 링크를 누르면 해당 서비스로 이동합니다. 각 서비스의 개인정보 처리 기준이 적용됩니다. 기존 코코나라 고객 안내에는 별도의 방문자 집계가 있습니다.

YouTube 영상

메인 화면은 YouTube의 개인정보 보호 강화 모드로 우도 영상을 불러옵니다. 재생 시 YouTube/Google에 IP 주소·브라우저 정보 등의 접속 정보가 전달될 수 있으며 해당 서비스의 처리 기준이 적용됩니다. 기기의 움직임 줄이기나 데이터 절약 설정이 켜져 있으면 자동으로 불러오지 않고 재생 버튼을 제공합니다.
